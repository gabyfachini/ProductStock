# 📦 Gerenciador de Estoque de Produtos

O **Gerenciador de Estoque de Produtos** é uma aplicação simples de console desenvolvida em **C#**, que permite gerenciar o estoque de produtos. Este projeto demonstra conceitos fundamentais de **Programação Orientada a Objetos (POO)**, como abstração, encapsulamento e herança.

---

## 🚀 Funcionalidades

- ✅ Cadastrar produtos com nome, fornecedor, categoria e quantidade em estoque.
- 🔄 Atualizar a quantidade de estoque dos produtos já cadastrados.
- 📜 Visualizar a lista de produtos cadastrados e seus respectivos estoques.
- ❌ Encerrar o programa através de um menu simples no console.

---

## 🏗️ Estrutura do Projeto

- **Stock.cs** → Classe abstrata que define as propriedades comuns (Produto, Fornecedor, Categoria, Quantidade) e os métodos abstratos.
- **Store.cs** → Herda de Stock e implementa as funcionalidades de gerenciamento dos produtos.
- **ProductList.cs** → Gerencia a lista de produtos com opções para adicionar, atualizar e listar.
- **Program.cs** → Arquivo principal que contém o menu e a interação com o usuário.

## 🚦 Como Executar

1. Clone ou baixe o repositório.
2. Abra a solução no Visual Studio ou na sua IDE de preferência.
3. Compile e execute o projeto (`F5` ou Run).
4. Utilize o menu no console para interagir com o estoque de produtos.
